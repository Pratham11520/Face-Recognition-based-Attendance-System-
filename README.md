# Biometric Workforce Management System

> Real-time facial-recognition attendance system developed for workforce verification and HR operations.

## Overview

A computer-vision attendance workflow designed to capture employee verification events and support operational reporting.

### Reported production impact

- Used daily by **200+ employees**
- Captures employee ID, timestamp, GPS, and verification image
- Client-side inference with TensorFlow.js reduced backend load by **40%**
- Automated reporting supports HR compliance and payroll workflows

## Technology

**Python · OpenCV · Dlib · TensorFlow.js · Computer Vision**

## Architecture

1. Employee presents for verification
2. Face detection / recognition is performed
3. Attendance event is recorded with associated metadata
4. Verification data feeds operational reporting
5. HR workflows use the resulting attendance records
