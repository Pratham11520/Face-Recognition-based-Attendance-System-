# Biometric Privacy Notes

Facial-recognition systems handle sensitive information and require stronger controls than ordinary application data.

Before production use, review:

- User consent and lawful processing requirements
- Biometric template protection
- Retention and deletion policies
- Access control
- Encryption in transit and at rest
- Audit logging
- False-match and false-reject handling

This repository is a technical portfolio project and does not by itself establish compliance with any particular jurisdiction.
